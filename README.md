# Vereinsshop – Präsentations-Demo (OTB)

Statische Seite: `index.html` (Fanshop, Teamshop, Werkstatt im 3D-Kabinen-Look).
Jeder Push auf `main` wird von Vercel automatisch veröffentlicht.

- Demo: Bestellungen werden nicht gesendet, es wird nichts bezahlt.
- `vercel.json` sperrt Suchmaschinen (noindex).
- Direkt in einen Shop: `?shop=fan`, `?shop=team` (Demo-Code TEUFEL26), `?shop=werkstatt`
